# Himpact MVP 验收标准（Acceptance Criteria）

## 1. 验收目标（结论先行）
MVP 通过标准：在本机 Workspace 可用前提下，用户在 30 秒内可完成“原油-传导-宏观-风险-事件-系统状态”六类客观判断，且系统不输出主观市场结论。

## 2. 验收范围
- 包含：面板 1~6、阈值告警、手工事件日志、系统状态、基础数据刷新链路。
- 不包含：自动新闻分类、NLP 摘要、情绪评分、市场状态引擎、多用户协作。

## 3. 功能验收（Functional）

### AC-F01 启动与连接
- Given：Desktop Session（本机 Workspace）可用，或 Platform Session 凭证可用。
- When：启动 Himpact。
- Then：系统在 60 秒内显示 `connected` 或 `degraded`，并展示最近一次成功更新时间。
- 失败条件：60 秒内无状态反馈，或状态字段为空。

### AC-F02 面板 1（原油主屏）
- 必须显示：Brent M1/M2、WTI M1/M2、Brent M1-M2、WTI M1-M2、Brent-WTI spread、1D/5D/20D。
- 通过条件：字段齐全、时间戳可见、数值可刷新。

### AC-F03 面板 2（成品油传导）
- 必须显示：Diesel proxy、Gasoline proxy、Diesel crack、Gasoline crack、1D/5D/20D。
- 通过条件：可见原始值 + 相对变化；缺失数据必须标明原因。

### AC-F04 面板 3（宏观价格传导）
- 必须显示：DXY、US2Y、US10Y、Gold（如启用）、1D/5D/20D。
- 通过条件：指标、单位、更新时间完整。

### AC-F05 面板 4（风险资产响应）
- 必须显示：BTCUSD（必选），ES/NQ（若启用）。
- 通过条件：实时值 + 变化率可见；不可用指标有明确占位说明。

### AC-F06 面板 5（事件检查板）
- 必须支持：新增、编辑、搜索、按时间排序。
- 事件字段：时间、分类、标题、来源、地理区域、标签、备注、确认状态、关联 Workspace 页面。
- 通过条件：新增后可检索，可按时间正确排序。

### AC-F07 面板 6（系统状态）
- 必须显示：session 状态、最近成功更新、历史回补时间、活跃订阅数、stale 标记、事件最后更新时间。
- 通过条件：任一状态变化可在 UI 明确反映。

### AC-F08 阈值告警
- 必须支持：价格上破/下破阈值、数据 stale、连接异常。
- 通过条件：给定样本数据可稳定触发一次且不重复刷屏。

### AC-F09 业务纪律
- 页面不得出现：情绪分数、状态评分、买卖建议、自动结论句。
- 通过条件：全页面文案检查无违规词汇与结论句模板。

## 4. 非功能验收（Non-Functional）

### AC-N01 性能与刷新
- 实时区 UI 刷新：目标 1 秒一次。
- 历史数据回补：启动一次 + 每 5 分钟回补。
- 通过条件：连续运行 30 分钟无明显卡死或大面积空白。

### AC-N02 稳定性
- 断线场景：应进入 `degraded/disconnected` 并提示，不得崩溃。
- 重连场景：恢复后状态自动回到 `connected`，并更新时间戳。

### AC-N03 可观测性
- 必须可追踪：最后更新时间、stale 状态、错误类型。
- 通过条件：QA 可根据状态字段复现并定位问题归属。

## 5. 测试场景（最小集合）
- TS-01 正常链路：启动 -> 连接成功 -> 六面板可见。
- TS-02 数据延迟：模拟某指标停更 -> 出现 stale 标记。
- TS-03 权限不足：模拟 entitlement 不足 -> 指标占位 + 原因说明。
- TS-04 阈值触发：喂入穿越阈值数据 -> 告警触发。
- TS-05 事件日志：新增/编辑/搜索/排序全通过。
- TS-06 文案纪律：全局扫描无主观判断文案。

## 6. Go/No-Go 规则
- Go：所有 P0 通过，P1 可接受且有豁免记录。
- No-Go：任一 P0 失败（连接不可用、核心面板缺失、数据不可追踪、主观文案违规）。

## 7. 角色责任映射
- Frontend Agent：AC-F02~F07、AC-F09 的 UI 实现与展示正确性。
- Backend Agent：AC-F08、AC-N01~N03 的数据服务与可观测性。
- LSEG Workspace Agent：AC-F01、连接与映射可用性。
- Integration/QA Agent：全量验收执行与 Go/No-Go 结论。

## 8. 当前假设
- 本文按 v1 技术栈：Python + lseg-data + Streamlit + SQLite。
- 指标启用集合以 metric registry 为准，可在不破坏契约前提下扩展。
