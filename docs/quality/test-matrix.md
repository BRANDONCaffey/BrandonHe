# Himpact Test Matrix（v1）

## 1. 目标（结论先行）
覆盖正常链路与关键异常链路，确保系统在“连接、数据、展示、告警、事件”五个维度可验收。

## 2. 测试维度
- 连接：建连、断线、重连
- 数据：正常、延迟、缺失、无权限、RIC 失效
- 展示：六面板渲染、状态占位、文案纪律
- 告警：阈值触发、stale、连接异常
- 日志：事件新增/编辑/检索/排序
